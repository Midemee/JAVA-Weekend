# Java Weekend Project Challenge

**Name:** Aramide Ashiwaju

## Projects

This repository contains three Java projects completed as console applications

### 1. SafeBank
A banking application developed to practise Java programming concepts through a banking-related use case. It focuses on handling banking operations and applying object-oriented programming and basic application logic.

### 2. TextLab
A text-processing application that performs different operations on text, including counting characters and words, cleaning whitespace, searching for words, replacing words, and checking for palindromes.

### 3. StudyVault
A file-based note management application that allows users to create, view, list, append, search, delete, export, and restore notes. It provides practical experience with Java file handling and input/output streams.

## Reflection

### 1. Which project was most challenging, and why?

StudyVault was the most challenging project because it required me to work more deeply with file handling and Java I/O. I had to understand how to create, read, append to, delete, and copy files while also handling possible errors. Working with streams and ensuring that notes were stored and retrieved correctly required careful implementation and testing.

### 2. Where did you use concepts from another topic?

I applied concepts from other Java topics across the projects. In StudyVault, I applied File I/O concepts, including buffered readers and writers, input and output streams, and exception handling. I also used JUnit to test application behaviour and verify that the methods worked as expected.

### 3. What would you improve with more time?

With more time, I would improve the structure and user experience of the applications, add more comprehensive test cases, and strengthen input validation and error handling.
